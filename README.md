# Databricks Medallion Architecture Project

## Overview

This project demonstrates a basic implementation of the Medallion Architecture using PySpark in Databricks.

## Architecture

### Bronze Layer

* Raw sales data ingestion

### Silver Layer

* Data cleaning
* Duplicate removal

### Gold Layer

* Sales aggregation by city
* Business-ready reporting

## Technologies Used

* Databricks
* PySpark
* Spark DataFrames
* ETL Concepts

## Key Operations

* Data Ingestion
* Data Cleaning
* GroupBy Aggregations
* Sorting and Analysis

## Outcome

Generated business insights from raw sales data using Bronze, Silver, and Gold layers.
